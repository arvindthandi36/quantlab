Position & risk

The public reference values inventory. It is not a promised liquidation price. Buying capacity includes all your resting buys; selling capacity includes all resting sells.

Quant view

Depth uses the top five levels per side. Flow uses the last 20 executions. Returns are log(price / previous price). Volatility is √sum(log return²) over up to 20 trade returns, unannualised. An empty value means insufficient data.
