# Phase 10 design — defined before implementation

> Historical phase record. Current core conventions and release status are in the root README, ASSUMPTIONS and Phase 11 release report. Test counts and runtime labels below describe this phase.


The chain is data/process → relationship → model → signal → position → execution → accounts → risk → validation → failure analysis. No synthetic result establishes real alpha.

## Information and time contract

A generic market owns named, separate Phase 6 venues. A private sequential process publishes synchronized positive price observations. Ordinary strategy inputs contain only the published prefix. There is no future path or RNG in these inputs. Model coefficients, signal and residual statistics are detached values. At observation t, a fit ends **before t**. Normalisation uses past residuals under that same vintage of the model; the current price enters only the numerator. Frozen models use an initial training block; rolling models use the last W past rows; walk-forward models are frozen within the next B unseen rows. Refitting does not retroactively rewrite history. An open trade retains its entry hedge and model for its convergence exit.

Prices are GBP per single unit, tick size £0.01. The common-factor return model uses one Gaussian factor plus independent idiosyncratic returns. Correlated arithmetic price increments use Phase 9 PSD validation/factorisation. Optional acyclic linear links construct Y=alpha+beta X+s, s[t]=mu+phi*(s[t-1]-mu)+sigma*Z[t]. The stable demonstration uses |phi|<1; phi=1 has a random-walk residual and is not cointegrated. Additive processes have unbounded mathematical support: nonpositive realizations fail visibly, never clip. Samples are finite teaching markets, not calibrated securities. Controlled breaks change beta, mean, volatility, persistence or idiosyncratic drift. Their future timing and true coefficients remain private in live views.

## Decision and execution contract

OLS uses centered/scaled least squares (SVD via NumPy), not explicit normal-equation inversion. Missing, constant and effectively constant predictors fail clearly. Conventional OLS standard errors are illustrative conditional IID/homoskedastic errors, not valid inference for arbitrary price regressions. AR(1) residual diagnostics have no p-values and are explicitly **not ADF or proof of cointegration**. PCA remains future optional work.

Prespecified entry/exit/stop/holding rules are visible. A long spread means +Y and -beta X units (rounded whole units); short reverses this. Dollar-neutral sizing is separate. Integer rounding leaves exposure. A queued pair executes the first leg now and the second only on an explicit next execution event, possibly after a market move. Finite book depth, both legs' spread, fees and deeper-level slippage apply. Missing fills are recorded, not invented. Gross and leg-imbalance preflights reserve possible fills of resting orders; opposite legs cannot assume simultaneous execution. Safeguards may stop new entries or request actual liquidation; liquidation can fail. End-of-sample residual inventory stays marked and visible.

All balances come from Phase 6 exact ledgers. Attribution uses actual inventories: qY*d(Y-beta_entry X) plus (qX+beta_entry*qY)*dX, minus signed execution shortfall relative to contemporaneous published marks and actual fees. This identity also covers leg risk; the residual is independently checked and fails loudly. The second term is a unit-hedge directional component, not automatically a market factor. Factor exposure uses past fitted return loadings where available; true process loadings are observer-only.

## Research and integration contract

Phase 5 registers studies before runs, separates development/evaluation seed addresses, records evaluation accesses and retains failed/losing rows. Parameter searches save every candidate, selection rule and training result before accessing a held-out block. No outcome-based seed search. Pair mining uses a fixed synthetic universe of unrelated walks and selects only on training net P&L. Evaluation results never revise selection. The intentionally invalid future-return oracle is isolated, labelled INVALID and cannot drive live trading.

Risk reads the actual stat-arb ledgers using Phase 9 portfolio, covariance, VaR/ES and stress functions. The Risk Lab will also display a consolidated linked-account view, with the cross-lab covariance assumption explicit. Existing desk risk limits retain their established scope; stat-arb has separate pretrade/position safeguards. Separate journals retain each session's actual commands; a linked risk display does not alter either book. The tutor accepts an explicit public stat-arb fact schema, clears future contexts on rewind and preserves actual learner evidence. No learner answers are generated by a demo.
