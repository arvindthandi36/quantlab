# Information boundaries

Normal explanations receive detached, server-owned public snapshots. Clients choose
a concept, lab, depth, risk method/order and mode; they cannot submit a replacement
snapshot, choose a filesystem path, provide private evidence or change the source label.

| Mode | Evidence permitted | Gate |
|---|---|---|
| Live | Current public book, own recorded fills/accounts, published option inputs, current risk report and past-only regression outputs | Default |
| Selected replay point | That public frame and its immediate predecessor | Verified replay, valid selected frame |
| Post-session public review | Public information in the ended snapshot, including already-matured markouts | Ended session or ended replay frame |
| Observer/model | Existing synthetic stock observer records, bounded to the first 30 | Explicit reveal, ended stock session/frame |
| Hypothetical | Detached reconstruction of selected public inputs | Explicit separate what-if request |

Rewinding a replay never consults the final financial session to explain an earlier
value. The final private journal, latent values, informed signals, event queue and
unpublished process state are not passed to normal explanation builders. A stat-arb
history is cut at the snapshot's published observation index before hypothetical
qualification scans; current X/Y is taken from that index, not a later appended row.

Observer results have a different response shape, are visibly labelled, and cannot
be passed to the explanation-to-quiz bridge. Post-session mode is not an automatic
observer reveal. There is no arbitrary future-frame/hindsight query hidden behind a
normal Explain control. To inspect later public evidence, select a later replay point.

The quiz bridge builds fresh `PublicContext` objects for the current point and asks
the existing tutor. Reading does not call encounter, grade, persist or submit answers.
Explicit quiz requests can create a question/encounter but cannot award assessed
mastery without an answer. User learning files are not used by automated UI exercises.

Risk-analysis seeds already present in the public risk report describe an independent
conditional scenario calculation, not the hidden future market path. Explanation
outputs omit save paths and random internal learning-source identifiers.

Inputs are rendered as text or escaped HTML. Search and learning are local; there is
no LLM/API call, telemetry, remote script, font or mathematics renderer. Documentation
links to primary finance education sources are optional outbound navigation only.

This is an application information boundary, not isolation from someone who already
controls the Python process, local filesystem or machine. Phase 11's local single-user
security limitations still apply.
