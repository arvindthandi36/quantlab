# Explain your QuantLab session

1. Open a lab and display a real value. Click its small **?** control, or use
   **Explain a value** to choose from that lab's main concepts.
2. Read **Your current value** and **Why is it this value?** The panel uses recorded
   Python results. For VWAP, select an order and inspect its actual price/quantity fills.
3. Choose **Maths**, **Quant** or **Interview** when ready. The number stays the same.
   Expand the complete calculation inputs for every recorded field.
4. Take another action and refresh the lab. **Why did this change?** compares the
   observed input states. If no earlier state was observed, the panel says so.
5. Follow **What does it affect?**, related concepts and the lab links. The Explain
   page also offers keyword search, six small relationship maps and an architecture view.

**Try the first VWAP example:** in a fresh default Trading session buy six market
units. The order fills two at £100.01 and four at £100.02. Click Explain VWAP. Its
actual value is £100.01667; the engine retains the exact GBP fraction 6001/60.

**Try a what-if:** in the same panel set a hypothetical buy size of 20. This now
uses the remaining displayed book. The amber result is separate from your actual
six-unit position. In Options try annual volatility `0.30` instead of `0.20`.
In Risk try common correlation `0.90`; the fast hypothetical risk result is clearly
labelled delta-normal, even when your main live report displays Monte Carlo VaR.

Opening a new financial lab can create its ordinary existing lab session. Opening
an explanation does not. If the selected lab has no displayed session yet, follow
the lab link first. A definition or engineering concept does not always have a
separate scalar value; unavailable session evidence is stated explicitly.

For replay, load and verify the original journal in its lab, select the desired
frame, then open Explain. The selected frame and its predecessor supply evidence.
Later events cannot appear merely because you previously viewed the end. Public
post-session review requires the ended frame. An explicit observer reveal is
available only after the stock session ends and is kept apart from quiz inputs.

**Quiz me on this** and **Interview me** ask the existing tutor using current public
evidence. Some topics need a relevant event first; unsupported scored topics retain
an ungraded interview prompt. Merely opening an explanation never increases mastery.

An equation explains a calculation. An assumption explains when that calculation
is a useful model. Exact accounting and deterministic replay do not make assumptions
true in a real market. Read **Assumptions — what if they are wrong?** before treating
a precise-looking risk number as a forecast.
