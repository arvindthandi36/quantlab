# Explanation style

Start with intuition, then the actual value and the inputs that produced it. Use
British English and define units before comparing quantities. A concept's short
definition, relevance, drivers, limitations and maths live in one registry; pages
consume that registry rather than keeping their own explanation copies.

Use four depths: **Beginner** (main inputs and intuition), **Maths** (equation and
every symbol), **Quant** (complete trace, relationships and assumptions), and
**Interview** (reasoning and challenges). Depth changes disclosure and teaching,
never the underlying calculated value.

Prefer “calculated from these recorded fills”, “observed changed input”, or
“under the configured model”. Dependency arrows do not establish real-world causation.
Do not manufacture causal percentages from a before/after comparison. A controlled
hypothesis may say exactly which inputs were changed and which were held fixed.

Differentiate **CALCULATION**, **MODEL ASSUMPTION**, **REAL-FINANCE CONTEXT** and
explicit **OBSERVER / SYNTHETIC MODEL EVIDENCE**. Never present a hypothetical or
constructed teaching example as the user's result. An unavailable or pending value
is not zero. Explain missing prerequisites instead of inventing values.

Display P&L accounting conventions accurately: stock realised P&L includes fees;
options/consolidated reports show gross components and separate fees. A cash inflow
is not necessarily profit. Per-unit Greeks, contract Greeks and portfolio Greeks
must remain labelled. Annual decimal volatility is not a percentage-point change.

Avoid filler, unexplained jargon and “obviously”, “simply” or “trivially” as teaching
shortcuts. Keep complete input evidence expandable so technical detail remains
available without overwhelming the first view. Show formula variables even when
their meaning seems familiar to an experienced reader.

Historical tutor questions and replay DTOs are frozen core interfaces. They retain
their existing pedagogical wording; the new explanation registry is authoritative
for the new panels, maps and browser glossary, not a rewrite of graded questions.
