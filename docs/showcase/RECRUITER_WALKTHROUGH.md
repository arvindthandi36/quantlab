# QuantLab in 3–5 minutes

Arvind Thandi · independent quantitative-finance learning, simulation and research platform.

1. **30 s — [README](../../README.md).** Scan capabilities and the synthetic/historical distinction.
   Launch with the documented commands; the [real Home screenshot](../assets/readme/home.jpg)
   also provides a quick visual overview.
2. **45 s — Home → order demo.** Predict BUY 10 MARKET. Reveal actual 3/4/3 fills and £100.023 VWAP.
   This demonstrates matching priority, conservation and ledger consequences.
3. **45 s — Delta hedge.** Observe multiplier-scaled delta, execute the stock hedge, then move spot.
   This demonstrates numerical pricing joined to real simulated execution and residual risk.
4. **30 s — VaR/ES.** Equal VaR, different average tail severity. This demonstrates explicit risk
   conventions rather than an unexplained dashboard score.
5. **45 s — Winner's curse.** Inspect the 50 equal-skill controls, locked selection and untouched
   evaluation. This demonstrates uncertainty and disciplined reporting, not a claimed strategy edge.
6. **30 s — [Architecture](../architecture/OVERVIEW.md).** Python owns calculations; journals,
   information boundaries and exact accounting make the system inspectable.
7. **30 s — [Limitations](../LIMITATIONS.md).** Artificial agents, simplified derivatives/risk
   assumptions and simulated historical execution are stated rather than hidden.

The in-app `/showcase` route links the same tour. Quick/showcase playback does not award personal
mastery. [Technical source route](TECHNICAL_WALKTHROUGH.md) for a deeper review.
